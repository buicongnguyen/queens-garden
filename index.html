How to play

Every board follows the same four rules.

  • Place exactly one queen in every row.
  • Place exactly one queen in every column.
  • Place exactly one queen in every colored region.
  • Queens cannot occupy adjacent diagonal cells. Longer diagonals are allowed; this is not standard chess queen movement.

Touch: tap once for a dot, again for a queen, and once more to clear. Swipe across cells when the full board fits; scroll larger boards to reach every cell. Mouse or keyboard: select Queen, Mark, or Erase, then activate a cell; arrow keys move around the board. Undo and Redo reverse a move or a whole swipe. Using Hint makes this attempt assisted. Daily garden uses the UTC date and cycles through the 20 saved 7 × 7 boards. Region numbers identify colors. Open Game → 3D garden to rotate or export the current position; Blender imports the download through File → Import → glTF 2.0.
